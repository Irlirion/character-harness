# 0008. Telegram через Bot API

Дата: 2026-10-17. Статус: выбор транспорта принят пользователем; детальная SDD
спецификация остаётся черновиком. Заменяет Telegram-часть решения 0003.

## Решение

Подключать Ладу как бота через Bot API. Первый срез — личка и одна тестовая группа,
где Лада сама решает, участвовать ли в разговоре. Worker использует HTTPS long polling.

## Причина

Для выбранного социального сценария достаточно Bot API. Создание через BotFather
и token устраняют пользовательский login-flow и хранение MTProto-сессии.

## Следствия

- В личке первым пишет пользователь. Для наблюдения за группой отключается Privacy Mode.
- История ограничена локальным журналом; нельзя обещать восстановление всей переписки.
- После неоднозначной отправки sendMessage сохраняется unknown без автоматического повтора.
- Работа со сторонними ботами не включена в MVP и потребует отдельной спецификации.
- Память, character engine и MCP сохраняются; права и история изолируются по чатам.
