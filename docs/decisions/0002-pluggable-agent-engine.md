# ADR 0002: Pi Agent или Codex как движок

Дата: 2026-10-03

Статус: принято требование; конкретный первый движок и транспорт предварительные.

## Контекст

Пользователь требует использовать Pi Agent или Codex как движок персонажей.

## Решение

Ввести EngineAdapter. Делегировать движку агентную сессию и tool loop, сохранив в харнесе персонажей, память, события, исполнение навыков, полномочия и оценку. Подключать инструменты мира через контролируемый шлюз. Генерацию инструментов выполнять в отдельном окружении мастерской.

## Последствия

Не требуется писать собственный основной цикл прямых вызовов LLM. Возможности движков различаются и отражаются в capabilities. Перенос персонажа между движками происходит через состояние харнеса, а не копированием внутренней истории. Для Codex требуется учитывать экспериментальный статус частей app-server; для Pi — закрепить актуальный пакет и API.
