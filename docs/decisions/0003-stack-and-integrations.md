# ADR 0003: стек и интеграции первой версии

Дата: 2026-10-03

Статус: выбрано для проектирования прототипа; пользовательский режим Telegram подтверждён.

## Решение

TypeScript, Node.js 24 LTS, pnpm workspaces, Pi SDK первым движком, PostgreSQL с SQL-миграциями, Zod для контрактов, Mineflayer и pathfinder для Minecraft Java, Teleproto/MTProto для пользовательских аккаунтов Telegram. Codex подключается вторым EngineAdapter.

Supervisor управляет отдельными процессами движков и адаптеров. Действия проходят capability gateway. Постоянная доставка строится на PostgreSQL inbox/outbox, leases и сверке состояния; IPC используется для локальной передачи. Мастерская исполняет код в отдельном ограниченном окружении.

## Причины

Общая TypeScript-экосистема уменьшает количество межъязыковых границ. Pi SDK даёт прямую точку расширения. PostgreSQL объединяет состояние и очереди первой версии. Mineflayer позволяет работать игровым клиентом без обязательного серверного плагина.

## Последствия

Нужно проверить совместимость версий и восстановление после сбоев. IPC не является sandbox. Пользователь выбрал клиентские аккаунты Telegram для общения и взаимодействия с ботами. Эти решения не означают, что код уже реализован.
