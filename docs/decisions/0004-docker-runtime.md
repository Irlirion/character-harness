# ADR 0004: Docker как обязательный runtime

Дата: 2026-10-03

Статус: первоначальное решение; топология заменена ADR 0007. Историческая запись: принято по требованию пользователя.

## Решение

Поставлять харнес как Linux Docker image и Compose-проект. Supervisor, движки и доверенные адаптеры запускаются внутри контейнера приложения. PostgreSQL и постоянные volumes отделены от него. Minecraft-сервер может быть внешним или тестовым Compose-сервисом. Авторизация Telegram выполняется одноразовым контейнером.

## Последствия

Рабочий запуск не зависит от установки Node.js/Pi на хосте. IPC остаётся внутри контейнера. Сессии и память переживают пересоздание контейнера. Исполнение сгенерированного кода требует отдельного ограниченного runner; Docker socket не выдаётся агенту. Dockerfile и Compose должны сопровождаться работающими entrypoints и проверкой восстановления, а не заглушками.
