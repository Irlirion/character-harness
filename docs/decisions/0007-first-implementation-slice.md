# ADR 0007: первый кодовый срез после ревью

Дата: 2026-10-04

Статус: принято для начала реализации в рамках авторизованной работы.

## Решение

Выбрать раздельные core/engine контейнеры и MCP Streamable HTTP. Это заменяет первоначальную топологию единого harness и stdio в ADR 0004/0005; общий каталог возможностей сохраняется. Использовать личную память в PostgreSQL и явную публикацию общего знания позднее. Создавать очищенную Pi-сессию на социальное событие в фиксированной аудитории; не разделять сырую историю разных каналов.

Первый срез содержит синтетическое общение, память, owner control и replay-safe запись заметок. Реальные адаптеры и голос подключаются после проверки зависимости Pi/MCP и Docker runtime. Не считать отсутствие голоса готовностью социального MVP.

## Обоснование

Архитектурное, ИБ- и техническое ревью выявили доступ engine к секретам единого контейнера и перенос приватного контекста через сохранённую историю. Раздельные контейнеры и короткие scoped sessions дают минимальную понятную границу. Явная память сохраняет личность между turns.

## Проверка и ограничения

Миграции, memory writes и replies используют PostgreSQL транзакции. Паузой отзывается epoch; изменяющие вызовы требуют текущего lease. Запуск и typecheck пока не подтверждены: registry недоступен и Docker daemon выключен. Установка зафиксированных в package.json версий и создание lockfile — обязательные следующие проверки.
