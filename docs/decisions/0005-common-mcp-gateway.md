# ADR 0005: общий MCP-шлюз возможностей

Дата: 2026-10-03

Статус: первоначальное решение; топология заменена ADR 0007. Историческая запись: принято пользователем.

## Решение

Публиковать Minecraft, Telegram, память и мастерскую через общий MCP-каталог. Pi и Codex используют его через свои engine adapters. Проверки полномочий, журналирование и диспетчеризация остаются в core. На первой стадии транспорт stdio внутри контейнера; для отдельного сетевого сервиса — Streamable HTTP.

## Последствия

Контракты инструментов не зависят от движка. Для stdio каждой сессии требуется своё соединение/процесс gateway с привязкой персонажа. Core сохраняет единое состояние и операции. MCP не заменяет игровой протокол, быстрые реакции, постоянный журнал или планировщик событий. Интеграционные испытания должны проверить реальные возможности MCP-клиентов Pi/Codex.
