# ADR 0006: постоянные персонажи по образцу Dots

Дата: 2026-10-04

Статус: продуктовый ориентир принят по требованию пользователя; детали runtime предложены.

## Решение

Считать экземпляр персонажа постоянным агентом, независимым от разговора и сессии движка. Добавить длительные обязанности, scheduler пробуждений, межканальную идентичность и политику уведомлений. Сохранить Pi/Codex, Docker и MCP как техническую основу.

## Последствия

Инициатива и восстановление ожиданий нужны в минимальном runtime. Для работы при выключенном устройстве владельца требуется всегда доступный сервер. Общая память сохраняет границы аудитории. Сходство относится к пользовательскому поведению Dots, а не к его закрытой реализации.
