# Безопасность

Проект находится на стадии экспериментального MVP. Исправления безопасности
выпускаются для актуального состояния ветки `main`; старые версии не поддерживаются.

## Сообщить об уязвимости

Используйте [приватный отчёт GitHub](https://github.com/Irlirion/character-harness/security/advisories/new).
Укажите затронутую версию, условия воспроизведения, ожидаемый и фактический результат,
а также возможное влияние. Удалите токены, персональные данные и реальные секреты
из примеров. Не публикуйте детали уязвимости в публичных issues до согласования
с владельцем репозитория.

## Безопасный запуск

- Держите core API на loopback (`127.0.0.1`), как в стандартном Compose.
  Публикация API в интернете требует отдельной проверки и защиты доступа.
- Храните credentials только в локальных `secrets/`, `.env` или хранилищах секретов.
  Не включайте их в коммиты, образы, журналы, игровые сообщения и отчёты об ошибках.
- Используйте отдельные случайные токены для owner, engine, audio и bridge.
  При утечке немедленно отзовите или замените секрет: удаление из Git его не отзывает.
- Устанавливайте Node-зависимости по lockfile с `--frozen-lockfile --ignore-scripts`.
  Проверяйте обновления Dependabot и результаты CI/CodeQL перед слиянием.
- Используйте тестовые аккаунты и данные для автономных персонажей. Текущий MVP
  не обеспечивает полноценные бюджеты исполнения и изоляцию любых внешних инструментов.
